\#Problem 1

``` r
nytransit = read.csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv") |>
  janitor::clean_names()|>
  select (line, station_name, station_latitude, station_longitude, route1:route11, entrance_type, entry, vending, ada) |>
  
  mutate(
    entry = recode_values(
      entry,
      "YES" ~ TRUE,
      "NO" ~ FALSE
    )
  )
```

The dataset contains information on the subway line, station name, the
station’s latitude and longitude, the routes from 1 to 11, the type of
entrances, and if you can have entry, whether it has a vending machine
and if it is ada compliant. The data have 1868 observations with 19
variables. The data can be tidied up more because route 1 - 11 all have
their own column with a lot of missing data.

How many distinct stations are there? Note that stations are identified
both by name and by line (e.g. 125th St 8th Avenue; 125st Broadway;
125st Lenox); the distinct function may be useful here.

``` r

  nrow()
```

``` r
nytransit_clean =
```

The baseline file had a note above, so we have to remove that with skip
= 1, I also removed any data that had response with NA, . , or blank.
And then I recoded the values from numbers in sex and apoe4 from 1/0 to
characters (male/female) (apoe carrier or not).Lastly, I removed anyone
who had MCI onset before basline age.

